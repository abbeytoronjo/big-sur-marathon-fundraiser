# Abbey Runs Big Sur 2027

A free GitHub Pages fundraising website for the 2027 Big Sur International Marathon benefiting Girls on the Run Central Coast.

## Files
- `index.html` — page structure and content
- `style.css` — visual design
- `script.js` — fundraising progress and future dynamic data
- `hero.jpg` — add your own hero photo here

## Publish on GitHub Pages
1. Create a new public GitHub repository.
2. Upload these files.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide your free `github.io` website address.

## Before publishing
- Replace `YOUR_DONATION_URL_HERE` in `index.html`.
- Add your own `hero.jpg`.
- Update `RAISED` in `script.js` as needed.

## Strava
The visual placeholder is ready. The live Strava integration should be added through OAuth rather than placing a Strava access/refresh token in this repository. Strava access tokens expire and refresh tokens are sensitive credentials.
